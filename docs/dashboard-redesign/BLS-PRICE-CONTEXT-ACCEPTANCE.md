## Source and limits

The fixed source is [BLS v2 CPI-U Personal Care Services](https://api.bls.gov/publicAPI/v2/timeseries/data/CUUR0000SEGC), series`CUUR0000SEGC`: U.S. city average, all urban consumers, monthly, not seasonally adjusted, index1982–1984=100. This is a government-published statistical aggregate, without establishment identities or underlying business/customer records. [Official series metadata](https://fred.stlouisfed.org/series/CUUR0000SEGC), [BLS item definitions](https://download.bls.gov/pub/time.series/cu/cu.item)

BLS does not publish average service dollar prices because services are differentiated. This feature therefore supports national index context only. It cannot provide a local service price, recommended price, competitor comparison or profit estimate. Sample methodology is explained, and the category observation count is explicitly unknown—not0 or a CPI-wide sample count. [BLS average-price limits](https://www.bls.gov/cpi/factsheets/average-prices.htm), [BLS sample design](https://www.bls.gov/opub/hom/cpi/design.htm)

The public single-series v2 GET succeeded without a key; BLS documents its response structure in the [v2 signature contract](https://www.bls.gov/developers/api_signature_v2.htm). BLS permits reuse of its public-domain statistics with attribution. No account, paid service or new dependency was introduced. [BLS API limits](https://www.bls.gov/developers/api_FAQs.htm), [BLS reuse policy](https://www.bls.gov/bls/linksite.htm)

## Implemented boundaries

- Pure`businessPriceContext.ts` accepts only one exact series and a versioned definition, positive finite monthly index values, unique valid completed months, a verified-fetch timestamp and raw-source hash. It rejects annual M13 rows, future/duplicate/out-of-range periods, ambiguous provider messages, unreviewed footnotes and changed units/base/seasonal adjustment/geography/source URLs.
- The only reviewed missing-value exception is October2025, source value`-`, exactly one footnote with code`X` and text`Data unavailable due to the 2025 lapse in appropriations`. It remains a separate`unavailable_observations` entry with exact source provenance, never zero or an interpolated index. Numeric plus unavailable months share the36-month count, age and uniqueness checks. The bounded view exposes only its month and fixed reason, plus separate numeric/source/unavailable counts; arbitrary source prose never enters the view. Unknown months, footnotes, altered explanations and contradictory numeric/missing records still fail closed.
- Only an exact matching month12months earlier permits a calculated percentage change. Missing comparison remains unknown. No interpolation, currency conversion, dollar formatting or pricing action exists.
- Freshness expires at the earliest of45days since retrieval, the start of the third month after the latest observation, or7days after a verified next-release date. These are conservative application rules, not BLS publication promises. Expired views suppress index/comparison numbers and show stale state; fresh retrieval cannot make old observations current.
- The disclosure uses four explicit locales. It separates the published observation months from the selected Finance period and explains geography, population, sample limits, retrieval-versus-publication date and official source links. It has no network or business-record reader.
- `scripts/refresh-business-price-context.mjs` makes only the fixed public v2 GET with no credentials/business payload, a20second deadline, no redirect following and128KiB maximum response. It validates before writing, saves original bytes outside Git by SHA-256, then prepares the repository snapshot for normal review/release. Failed reads do not overwrite a previous snapshot. `--check` validates without writing. The pure`validateBlsPriceBytes` entry also validates already captured bytes against the exact v2 URL, timestamp, optional pinned hash, UTF-8 and size limit without fetching. Run with the existing Node runtime; no package installation is needed.
