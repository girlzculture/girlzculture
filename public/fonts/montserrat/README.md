Unmodified Montserrat static WOFF2 files (Regular 400, Medium 500, SemiBold 600,
Bold 700) from the official upstream repository, pinned to commit:

https://github.com/JulietaUla/Montserrat/tree/555facfb2a18c72c3c0380f0d9c0f060453a9058/fonts/webfonts

License: SIL Open Font License 1.1, included in OFL.txt.

These fixed weights retain the existing Engine font selection while avoiding
the thin rendering reproduced with Google's variable resource in Windows
Playwright WebKit. No font outlines or visual design were changed.
